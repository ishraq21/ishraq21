## What I've built

**RAGnetic** ![GitHub stars](https://img.shields.io/github/stars/Ishraq21/RAGnetic?style=flat)
[RAGnetic](https://github.com/Ishraq21/RAGnetic) is an open-source framework for deploying AI agents on your own servers. It supports LangChain and LangGraph workflows, vector stores, YAML-based orchestration, LoRA training, and observability dashboards, and it is built for secure, multi-tenant, on-premise setups.

**AI request platform, San Diego Unified**
A Django, HTMX, and PostgreSQL platform with role-based access for requestors, analysts, and admins. Its streaming Claude assistant lets staff and public users submit, track, and update requests in plain English. It confirms before it writes, rate-limits by IP, and gives each role only its own tools. It also has Microsoft Entra ID sign-on, audit trails, and dashboards.

**Cryo-EM data delivery, NanoImaging Services**
GMP-compliant Django tools that move cryo-EM imaging data through AWS S3, with Celery for parallel processing and Docker for deploys. They replaced manual data handling with automated ingestion and tracking.

**Identity automation, CSUN**
Python, Bash, and LDAP automation for 10k+ user accounts, plus an API-driven provisioning system and serverless AWS Lambda sync. It cut processing time by 50%.

**Tide & Treats**
A [custom cake ordering site](https://tideandtreats.com) with an AI cake designer built on Google's Gemini API, a flavor-personality quiz, and an order form.
